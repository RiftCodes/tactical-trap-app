## Introduction

Bienvenue dans l'App de Contrôle de Serrure Bluetooth Tactical Traps ! Cette application vous permet de contrôler votre serrure Tactical Traps compatible Bluetooth à l'aide de votre smartphone. L'app fournit un accès sécurisé et pratique à votre serrure avec des fonctionnalités comme la vérification du code PIN, la surveillance de l'état et le contrôle à distance.

### Ce qui est Inclus

- **Serrure Bluetooth** : Serrure haute sécurité avec connectivité Bluetooth
- **App Mobile** : Application multiplateforme pour iOS et Android
- **Manuel Utilisateur** : Ce guide complet
- **Kit d'Installation** : Matériel de montage et instructions

## Commencer

### Exigences Système

- **Smartphone** : iOS 12+ ou Android 8+
- **Bluetooth** : Bluetooth 4.0 ou supérieur
- **Permissions** : Permissions de localisation et Bluetooth requises

### Configuration Initiale

1. **Installer l'App** : Télécharger depuis l'App Store ou Google Play
2. **Activer Bluetooth** : Allumer Bluetooth dans les paramètres du téléphone
3. **Accorder les Permissions** : Permettre l'accès à la localisation et Bluetooth
4. **Scanner les Serrures** : Utiliser le bouton de scan pour trouver les serrures à proximité

## Fonctionnalités de l'App

### Interface Principale

- **Écran d'Accueil** : Affiche l'état de la serrure connectée et les contrôles rapides
- **Bouton de Scan** : Rechercher les serrures disponibles dans la portée
- **Contrôles de Serrure** : Verrouiller/déverrouiller, vérifier l'état et les paramètres
- **Gestion des Appareils** : Voir et gérer les serrures connectées

### Fonctionnalités de Sécurité

- **Vérification du Code PIN** : Authentification sécurisée basée sur le code PIN
- **Communication Chiffrée** : Toutes les données sont chiffrées
- **Auto-verrouillage** : Verrouillage automatique pour la sécurité
- **Journaux d'Accès** : Suivre l'historique de verrouillage/déverrouillage

## Se Connecter à Votre Serrure

### Connexion Initiale

1. **Allumer** : S'assurer que votre serrure a de l'énergie (batterie ou alimentation externe)
2. **Scanner** : Appuyer sur le bouton de scan dans l'app
3. **Sélectionner la Serrure** : Choisir votre serrure parmi les appareils découverts
4. **Entrer le Code PIN** : Saisir le code PIN de votre serrure quand demandé
5. **Vérifier** : Attendre la confirmation de connexion

### Gestion du Code PIN

- **Code PIN par Défaut** : Généralement configuré en usine (vérifier la documentation de votre serrure)
- **Changement de Code PIN** : Peut être modifié via les paramètres de la serrure
- **Récupération du Code PIN** : Contacter le support si le code PIN est oublié

### État de la Connexion

- **Connecté** : Indicateur vert montre une connexion active
- **Déconnecté** : Indicateur rouge montre aucune connexion
- **Qualité du Signal** : Affiche la qualité de la connexion

## Opérations de Base

### Verrouiller/Déverrouiller

1. **Assurer la Connexion** : Vérifier que la serrure est connectée à l'app
2. **Choisir l'Action** : Sélectionner le bouton Verrouiller ou Déverrouiller
3. **Confirmer** : Attendre la confirmation de l'opération
4. **Vérifier** : Vérifier l'état de la serrure pour confirmer l'action

### Vérification de l'État

- **État Actuel** : Montre si la serrure est verrouillée ou déverrouillée
- **Niveau de Batterie** : Affiche la batterie restante
- **Qualité du Signal** : Montre la force de la connexion
- **Dernière Activité** : Horodatage de la dernière opération

### Actions Rapides

- **Verrouillage en Un Clic** : Bouton de verrouillage rapide pour la sécurité immédiate
- **Déverrouillage en Un Clic** : Déverrouillage rapide pour l'accès autorisé
- **Actualiser l'État** : Mettre à jour les informations de l'état de la serrure

## Fonctionnalités Avancées

### Paramètres de Serrure

- **Minuteur d'Auto-verrouillage** : Définir le délai de verrouillage automatique
- **Alertes Sonores** : Activer/désactiver les sons d'opération de serrure
- **Retour Haptique** : Retour tactile pour les opérations
- **Indicateurs LED** : Contrôler les lumières d'état de la serrure

### Gestion des Utilisateurs

- **Utilisateurs Multiples** : Ajouter des membres de la famille ou des employés
- **Niveaux d'Accès** : Définir différents niveaux de permissions
- **Restrictions Temporelles** : Limiter l'accès à des heures spécifiques
- **Accès Invité** : Codes d'accès temporaires

### Surveillance et Journaux

- **Historique d'Activité** : Voir toutes les opérations de serrure
- **Suivi des Utilisateurs** : Voir qui a accédé à la serrure et quand
- **Alertes** : Recevoir des notifications de tentatives non autorisées
- **Rapports** : Générer des rapports d'accès

## Dépannage

### Problèmes Courants

#### Problèmes de Connexion

- **Serrure Non Trouvée** : S'assurer que la serrure est allumée et à portée
- **Échec de Connexion** : Vérifier le code PIN et réessayer
- **Signal Faible** : Se rapprocher de la serrure
- **Problèmes Bluetooth** : Redémarrer Bluetooth sur votre téléphone

#### Problèmes d'Opération

- **Serrure Ne Répond Pas** : Vérifier le niveau de batterie et la connexion
- **Code PIN Non Accepté** : Vérifier que le code PIN est correct
- **App Se Ferme** : Redémarrer l'app et se reconnecter
- **Réponse Lente** : Vérifier la force du signal

### Messages d'Erreur

- **"Appareil Non Trouvé"** : La serrure est hors de portée ou éteinte
- **"Échec de Connexion"** : Code PIN incorrect ou serrure occupée
- **"Bluetooth Non Disponible"** : Activer Bluetooth sur votre téléphone
- **"Permission Refusée"** : Accorder les permissions d'app requises

### Procédures de Réinitialisation

- **Réinitialisation de l'App** : Effacer les données de l'app et se reconnecter
- **Réinitialisation de la Serrure** : Réinitialisation d'usine de la serrure (consulter le manuel de la serrure)
- **Réinitialisation du Téléphone** : Redémarrer le téléphone et réessayer

## Sécurité et Maintenance

### Meilleures Pratiques de Sécurité

- **Garder le Code PIN Secret** : Ne pas partager votre code PIN avec d'autres
- **Changements Réguliers de Code PIN** : Mettre à jour le code PIN périodiquement
- **Surveiller l'Accès** : Vérifier les journaux d'activité régulièrement
- **Téléphone Sécurisé** : Utiliser le verrouillage du téléphone et le chiffrement

### Maintenance de la Serrure

- **Vérifier la Batterie** : Surveiller le niveau de batterie régulièrement
- **Nettoyer les Contacts** : Maintenir les contacts de la serrure propres
- **Protection Météo** : Protéger des conditions extrêmes
- **Tests Réguliers** : Tester le fonctionnement de la serrure mensuellement

### Procédures d'Urgence

- **Téléphone Perdu** : Contacter le support pour désactiver l'accès
- **Code PIN Oublié** : Utiliser la méthode d'accès de secours
- **Malfonction de Serrure** : Contacter le support technique
- **Panne d'Énergie** : Utiliser l'alimentation de secours si disponible
